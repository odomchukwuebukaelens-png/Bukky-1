# Google Flow image prompts: Video 01

**How to use**
1. Make image 1 first. Download the best result.
2. For every later image, add image 1 as a reference ("ingredient") so the family stays consistent.
3. Pick **16:9** for every image unless a different ratio is noted. Choose the best image model offered (Nano Banana Pro or Imagen 4).
4. Download each result as a PNG and name it as shown, for example `01_charsheet.png`.
5. Put all the files in one Google Drive folder, share it as "Anyone with the link can view", and send me the link.

Add this **style line** to the end of every prompt:

> Flat 2D cartoon illustration for an animated horror YouTube channel. Clean thick dark outlines, flat cel shading with one soft shadow tone, simple rounded shapes, large expressive eyes with glossy highlights. Limited palette of deep navy, muted teal and warm wood browns, with sickly acid-green and mustard-yellow accent light. No text, no watermark.
